# Data

This Letter uses **public end-of-day market data only**.

## Sources

- **Yahoo Finance** — https://finance.yahoo.com/
  Daily close prices for S&P 500, NASDAQ 100, Euro Stoxx 50, FTSE 100, GICS sector
  sub-indices, VIX, WTI crude oil, gold.

- **FRED (St. Louis Fed)** — https://fred.stlouisfed.org/
  US 2-year and 10-year Treasury yields, investment-grade and high-yield credit
  spreads, Fed liquidity indices.

Download scripts are included in `notebooks/notebook_01_preprocessing.ipynb`.

## No proprietary data

No proprietary, licensed, or private data is used at any stage of the analysis.
Every empirical figure in the Letter is reproducible from the public sources above
using only the notebooks and scripts in this repository.
